# Product Backlog

**Project:** Online Shop
**Product Owner:** Member 1

## User Stories

| ID     | User Story | Priority | Assigned To |
|--------|------------|----------|-------------|
| US-101 | As a customer, I want to log in with my email and password, so that I can access my personal account. | High | Developer A |
| US-102 | As a customer, I want to search products by keyword, so that I can find items quickly. | High | Developer B |
| US-103 | As a customer, I want to add items to a shopping cart, so that I can buy several products at once. | Medium | Developer C |
| US-104 | As an admin, I want to view order history, so that I can track sales and revenue. | Medium | Unassigned |
| US-105 | As a customer, I want to receive an email confirmation after placing an order, so that I know my purchase was successful. | Low | Unassigned |

## Acceptance Criteria

### US-101
- User can enter an email and password
- Invalid credentials show an error message

### US-102
- Search returns products whose name contains the keyword
- An empty result shows "No products found"

### US-103
- User can add and remove items in the cart
- Cart shows the total price
